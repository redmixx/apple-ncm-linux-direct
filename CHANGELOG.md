### Added

- Read-only Apple CDC-NCM diagnostics.
- Runtime module-alias support detection for Apple `05ac:1905` and `1902`.

- Safe out-of-tree module build and inspection helpers.
- Dry-run-first Linux address configuration and rollback.
- Ping and `iperf3` link tests.
- macOS, Linux, Secure Boot/MOK, DGX Spark/GX10, benchmark, architecture, and
  troubleshooting documentation.
